## 买之前，先确认这三件事

**第一，流量是双向计费的。** 所有流量计费套餐按上行加下行合计统计，标 100GB 实际单向只能用 50GB。额度用完会暂停，可以自助购买流量重置，或者提交工单补差价升级套餐。很多人对比单价时没算这一层，得出的结论会偏乐观一倍。

**第二，要实名，还要绑定省份。** 这是官方下单页写明的规则：

> 本站所有专线产品均采用省级白名单措施，该产品仅允许一个省份的 IP 连入。需中国身份信息实名。

流程上就是注册（国内手机号）→ 实名认证（姓名、身份证号、手机号一致性验证）→ 下单时选择可连入省份。开通后只有该省的 IP 能连入口，省份之后可以切换。如果你没法或不愿提供中国身份信息，这个产品可以直接从备选里划掉。

**第三，共享带宽是峰值，不是承诺速率。** 流量计费套餐标注的 150~500Mbps 是共享峰值，不保证持续跑满。有第三方测评在 150M 档实测下载速度 89Mbps 左右，没到理论值——这在共享带宽产品里比较常见。如果你的业务要求 24 小时持续高速率，直接跳到下面的独享带宽部分。

## 下单流程，以及几个容易踩的坑

整个流程走下来不复杂：注册账号（国内手机号）→ 实名认证 → 选产品线（沪美流量计费或沪美独享带宽）→ 选套餐、操作系统和购买周期（一次性、月付、季付、半年、两年、三年都有）→ 填优惠码 → 支付宝付款 → 官方标称约 1 分钟自动开通 → SSH 或 RDP 连入口地址开始用。

真正容易出问题的是这几处：

- **白名单省份**：选你实际所在或实际使用的省份。选错了，外省 IP 连不上入口。好在省份可以随时切换，不算不可逆的错误。
- **双向流量**：再强调一次，标称额度除以二才是单向可用量。选套餐时按这个口径算，不要按标称值规划。
- **延迟口径**：124~134ms 是上海入口到美国出口的端内延迟，你本地到上海入口还要再加一截。第三方实测三网连上海电信入口的 tcp ping 在 28~33ms 左右，所以体感总延迟一般在 140~160ms。另外，在这台机器上 ping 任何目标 IP 都会显示 124ms 往上，因为延迟从入口算起——这是架构特性，不是故障。
- **退款口径**：官方知识库写明，仅质量问题支持退款，需要工单里提交测试截图和具体问题，由商家审核判断，且不支持开通后更换地域。所以合理的做法是先月付测试，确认线路满足业务需求再考虑长周期。

## 几个常见问题

**一定要中国身份证吗？** 是。所有专线产品都要求国内手机号注册加身份一致性地验证，这一步过不了就没有然后了。

**移动、联通网络能用吗？** 能。入口是上海电信，第三方实测三网连入口的延迟都在 28~33ms 区间，电信 28ms、联通 30ms、移动 33ms，差别不大。

**出口 IP 质量怎么样？** 2023 年底的一份第三方测评显示，出口为美国原生 IP（洛杉矶，Nearoute Limited AS51847），TikTok 区域识别为 US，ChatGPT、Amazon Prime Video 解锁正常，Netflix 仅 Originals。要注意的是不同风控数据库打分分歧很大——同一批 IP，Scamalytics 给了 0 分，IPQualityScore 给了 93 分。打算拿去做敏感平台运营的话，建议先月付验证，别只看一份测评下结论。

**两个 IP 怎么用？** SSH 或 RDP 连入口，进去就是出口机，对外业务走出口 IP；入口 IP 不对外提供服务。理解成"一端机器、双独立 IP"就行。
